Lets a bot read your finances in PocketSmith, through PocketSmith's own service. Ask it things
like:

- "Where did my money go last month, compared with the month before?"
- "Which subscriptions am I still paying for?"
- "Will I have enough in my account for the rent at the start of March?"

Activating it signs the bot in: you approve it on
PocketSmith's own page. It connects to PocketSmith's read-only service, so the bot can never
change your data: it does not categorise, edit or delete transactions.

The bot only reads: nothing in PocketSmith is changed.
