Gives a bot exact weather for any place, from Open-Meteo's free weather service. Ask it things
like:

- "Will it rain in Lisbon on Saturday afternoon?"
- "What's Tokyo usually like in the first week of April?"
- "Every morning at 7, tell me if I need an umbrella."
- "Let me know if frost is coming this week."

There is nothing to set up and nothing to sign in to. Activate it for a bot and ask.

Open-Meteo's free service is for personal, non-commercial use, up to 10,000 requests a day,
which a bot stays far below. Its data is shared under CC BY 4.0, so pages the bot makes from
it name Open-Meteo.
