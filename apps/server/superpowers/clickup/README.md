Lets a bot work in your ClickUp, through ClickUp's own service. Ask it things like:

- "What's due this week in the Marketing space?"
- "Turn these meeting notes into tasks in the Website list, assigned to me."
- "Log two hours on the landing page task."

There is nothing to set up. Activate it for a bot, press **Sign in**, and choose the Workspaces
it may use on ClickUp's own page; to change them later, sign in again. It works on every ClickUp
plan, but ClickUp limits how many times a day it can be used: 100 on the free plan, more on paid
ones.

The bot reads freely and can create tasks, comments and docs. It asks before it changes, moves or
deletes a task you did not tell it to.
