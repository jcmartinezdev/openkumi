Lets a bot keep an eye on web pages for you, and speak up only when something you care about
changes. Ask it things like:

- "Tell me when these headphones drop below €200."
- "Let me know when the size 42 is back in stock."
- "Watch the consulate's booking page for a slot before March."
- "Tell me when this blog has a new post."

There is nothing to set up and nothing to sign in to. Activate it for a bot and ask.

Each watch is a scheduled task, which you can see, pause or delete under Scheduled tasks. It
keeps what it last saw in the bot's files, under `watches/`. A page that needs you to be signed
in works once you have signed in to it in the bot's browser.

A watch only looks and tells you. It never buys, books or fills in anything; that is for you to
decide when it tells you.
