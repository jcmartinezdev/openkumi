Lets a bot work in your Klaviyo, through Klaviyo's own service. Ask it things like:

- "How did last week's campaigns do compared with the month before?"
- "Which flow brings in the most revenue?"
- "Draft a campaign for the spring sale to the Engaged segment."

Activating it signs the bot in: you allow it on Klaviyo's
own page; with more than one Klaviyo account, choose which one there. You need to be an Owner,
Admin or Manager in that account. The bot gets Klaviyo's core set of tools, which keeps it quick;
rarer tasks are left to you in Klaviyo.

The bot reads freely and drafts campaigns for you to check. It asks before it changes a profile,
list or segment, or schedules or sends anything.
