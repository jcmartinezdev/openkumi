Lets a bot read the meetings Fathom recorded for you, through Fathom's own service. Ask it things
like:

- "What did the client ask for in yesterday's call?"
- "Which action items did I take on this week?"
- "Get me ready for my call with Sara: what did we talk about last time?"

Activating it signs the bot in: you approve it on Fathom's
own page. The bot reaches the meetings your Fathom account can see, and no others.

The bot only reads: nothing in Fathom is changed.
