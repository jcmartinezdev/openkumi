Lets a bot read your Otter.ai recordings, through Otter's own service. Ask it things like:

- "What did the client say about the deadline in yesterday's call?"
- "Find the meeting where we talked about the office move."
- "Pull out every action item from this morning's stand-up."

Activating it signs the bot in: you approve it on
Otter's own page. The bot reaches the conversations you recorded or that were shared with you.

The bot only reads: nothing in Otter is changed.
