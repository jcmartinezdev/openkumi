Lets a bot read and draw on your Miro boards, through Miro's own service. Ask it things like:

- "Sum up the retro board from Friday: what came up most?"
- "Draw our signup flow as a diagram on a new board."
- "Group the sticky notes on the research board by theme."

There is nothing to set up. Activate it for a bot, press **Sign in**, and choose a team on Miro's
own page. Miro connects one team at a time for all the apps you use with it: signing a bot in, or
connecting another app, ends the connection before it. On Miro Enterprise an admin has to turn it
on first. Miro limits how many times a day it can be used: 100 on the free plan, more on paid
ones.

The bot reads freely and can add to a board. It asks before it changes or removes what is
already on one, or shares a board.
