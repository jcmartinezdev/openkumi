Lets a bot work on your Webflow sites, through Webflow's own service. Ask it things like:

- "Draft three blog posts in the Articles collection from these notes."
- "Which pages are missing a meta description? Write them."
- "What came in through the contact form this week?"

There is nothing to set up. Activate it for a bot, press **Sign in**, and choose a workspace and
the sites it may use on Webflow's own page; only a site's owners and admins can allow it. A few
tools that work on the canvas need the Webflow Designer open, with the MCP Bridge App Webflow
installs; everything else works without it.

The bot reads freely and leaves its changes unpublished for you to check. It asks before it
publishes anything or deletes a page, item or asset.
